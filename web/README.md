# Web Dashboard

Next.js web dashboard for AI Operator.

**Status:** To be built — new, clean frontend

## Planned Pages
- `/` — Dashboard: system status, recent commands
- `/approvals` — Review and approve pending actions
- `/history` — Command history and logs
- `/integrations` — Manage connections (Gmail, LinkedIn, etc.)
- `/settings` — API keys, preferences

## Tech
- Next.js (App Router) + TypeScript
- Tailwind CSS
- Connects to Python backend via REST API
